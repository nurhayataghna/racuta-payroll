# Racuta Payroll System v2

Sistem penggajian borongan penjahit Racuta.

## Fitur
- Login Admin/Master dan karyawan
- Karyawan input produksi sendiri
- QC PASS / REWORK / REJECT
- Master tarif per produk/proses
- Periode payroll
- Generate slip dari produksi PASS
- Status pembayaran unpaid / approved / paid
- Slip gaji printable
- Row Level Security melalui Supabase

## Environment
`NEXT_PUBLIC_SUPABASE_URL` dan `NEXT_PUBLIC_SUPABASE_ANON_KEY` harus dikonfigurasi di Vercel.
